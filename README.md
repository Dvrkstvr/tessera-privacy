# tessera-privacy

The privacy policy of Tessera, the daily picture-logic puzzle game, published with GitHub Pages:

**https://dvrkstvr.github.io/tessera-privacy/**

The game opens this address from Settings › Privacy (its default, which Remote Config `privacy_policy_url` can override) and the itch.io page links to it, so keep `index.html` at the root. Pages publishes `main` as it is (Settings › Pages › Deploy from a branch: `main`, `/ (root)`; no build, `.nojekyll`).

When what the game stores changes (a new Cloud Save key, a new analytics event, a new service), update the policy and its date here, together with the game's change.
